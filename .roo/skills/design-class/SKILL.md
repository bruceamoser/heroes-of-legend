# Develop a class

Read design/class.md, class records and development rules. Classes set discipline prices, starting grants and exclusive signature choices at levels 1/3/7. No multiclassing. Shared abilities remain open to characters meeting requirements. Signature options should be slightly stronger and express identity. Present costs clearly and update indexes and build coverage if counts change.
