# Create a focused issue

Create an issue before implementation. Describe one concern, relevant current design paths, and observable acceptance criteria. Use structured arguments or a body file with gh; do not embed complex prose in shell quoting. Note the number for the branch and PR. Split unrelated work. Existing rules are under design/, not historical editions.

Follow [project instructions](../../../.github/copilot-instructions.md).
