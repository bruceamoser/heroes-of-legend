# Review rules, source and PDF integrity

Review independently from implementation before merging. Check the actual diff against current rules and Bruce’s decisions. Verify links, IDs, card counts, attack/defense perspectives, conditions, requirements and equipment grants. Run affected audits; shared-source or deletion work requires both builds. Inspect rendered pages, art uniqueness and summon markers. The creature-art manifest must cover every creature and preserve stable VTT references. Check language rules and grants in both books when changed. Verify release bundles contain both PDFs and matching checksums. Do not confuse structural correctness with balance or infer approval from an older PR.

Follow [project instructions](../../../.github/copilot-instructions.md).
