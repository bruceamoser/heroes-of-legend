# Submit current book work

Commit on `codex/<issue>-<description>`, push, and create a PR against `main`. Lead with the concrete reader or table-use problem and resulting behavior. Include `Closes #N` for every resolved issue, changed sources, actual validation and any new design decisions. Attach the PR to the current task. Then review the current PR and squash merge it when checks pass and findings are resolved. Raise decisions or unresolved concerns that need Bruce’s judgment.

Follow [project instructions](../../../.github/copilot-instructions.md).
