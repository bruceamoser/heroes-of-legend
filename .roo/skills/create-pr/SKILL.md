# Submit current book work

Commit on codex/<issue>-<description>, push, and create a PR against main. Lead with the concrete reader or table-use problem and resulting behavior. Include Closes #N for every resolved issue, changed sources, actual validation and any new design decisions. Attach the PR to the current task. Do not claim tests or independent review that did not run. Approval of previous PRs does not approve this one.
