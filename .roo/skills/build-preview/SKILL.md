# Build and inspect the books

Read release/README.md and the book README files. Run scripts/build_starter_kit.py to build and audit both books. Inspect rendered pages, especially tables, cards, text bounds, art fit and references. The output is a digital playtest edition, not a certified print PDF. Generated files are not editable sources. Package both PDFs for every starter-kit release.

Follow [project instructions](../../../.github/copilot-instructions.md).
