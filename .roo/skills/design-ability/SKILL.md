# Develop an ability

Read design/card-conventions.md and relevant current rules. Start with a fantasy and useful player choice. Write evocative narrative followed by exact action, attribute, targets, outcomes, time, limits and requirements. Use discipline ranks and level 1/3/7 gates without prerequisite-card chains. Ordinary items are flavor; effects live on cards. Update navigation and directory summaries, run audits and inspect the book. New mechanics require Bruce’s review.

For equipment training, check the complete tier/rank progression, matching item and price, origin grants, example inventories and derived resistance. Update book coverage counts and summaries as well as navigation; rebuild both books. Downstream VTT catalogs follow the reviewed canonical source.

Follow [project instructions](../../../.github/copilot-instructions.md).
