5. [08-disciplines:265] Broken: the closing line 'No shortcuts. No wildcards.' re-argues the rationale already given at 08:214. Expected: the point stated once. Fix: cut the repeat at 265.

SUBSTANTIVE (prose, cross-chapter, content)
1. [08-disciplines:133] Broken: 'Every card (spell, ability, skill) follows a three-tier ladder' puts skills inside the Discipline-gated ladder, contradicting the chapter's own exemption at 08:15 and 08:113, the no-prereq basics at 08:214, and ch07 (skills gate nothing). Expected: 'Every card (spell, ability)' plus the basics carve-out. Fix: drop 'skill' from the parenthetical. Blocking per f-006.
2. [08-disciplines:107] Broken: 'A Blade of the Last Ember grants Fire rank 1 while you wield it. Set it down, lose the power.' ch17 conditions item grants on attunement, not wielding (ch17:27; ch17:512 'If you stop attuning to an item, any Disciplines it granted are lost'). Expected: grants Fire rank 1 while attuned; ending attunement loses it. Fix: replace the wield and set-down wording with attunement and add the @sec-chapter-magic-items cross-reference. Reconciliation: f-001 would rename the item, f-004 keeps the name and fixes the condition; ch17:46 grants 1 Fire from the blade while attuned, so keep the name and fix the condition.
3. [08-disciplines:263] Broken: Master Ember Lance 'a burning patch that deals 2 damage per round for 3 rounds'. Expected: the locked named-condition form, which ch11:134 gives as 'leaves a burning patch (Burning 2)'; Burning's duration is action-based, not a fixed three-round span (ch21). Fix: replace the round-count prose with '(Burning 2)'.
4. [08-disciplines:248] Broken: 'Melee weapons use their listed damage values and add Brawn' credits weapons with damage values of their own; ch15 carries no damage column ('The weapon never changes these numbers') and 08:250 in the same chapter agrees. Expected: melee attack cards add Brawn (Agility for Finesse) to the card's budget row. Fix: reword 248 to key melee damage to the attack card's budget row, not the weapon's own values.
5. [08-disciplines:210] Broken: 'Weapons may list their own Discipline combos as entry requirements' limits the rule to weapons, yet armor and shields carry Armor and Protection rank requirements (ch16:84-90, ch22:344-364) and ch16:84 sends readers here for the full rules, which the chapter never states. Expected: the entry-requirement rule covers armor and shields as well. Fix: extend the sentence at 210 to name armor and shield rank requirements and cross-reference ch16.
6. [08-disciplines:181] Broken: the Ember Lance callout's Arcanist line reads 'flat 2 DP + Fire rank 1 at Home (1 DP) = 3 DP total', charging a rank the Arcanist already holds from her class grant (08:86, 08:257); the same callout's Brimstone line (08:185) and the worked build (08:259 'her Arcanist home cost for Fire rank 1 was already paid at creation') both treat it as paid. Expected: 2 DP total for the Arcanist. Fix: drop the Fire rank 1 charge from the Arcanist line so it reads flat 2 DP, rank already held.

DESIGN (needs the lead designer; recommended default named)
1. [08-disciplines:248] Broken: the Novice attribute-scaled base is printed 1/2/3 while the same sentence derives every base as 'budget minus 3', and the Novice budget is 2/4/6, so 2/4/6 minus 3 gives -1/1/3; the printed 1/2/3 equals the ch09 Basic-attack floor (09:251 'Damage remains 1/2/3 + Brawn'), which ch21:47 mirrors. The subtraction rule and the printed Novice triplet cannot both hold; Adept 3/6/9 and Master 6/12/18 do fall straight out. RECOMMENDED DEFAULT: keep the printed Novice floor 1/2/3, scope the 'budget minus 3' wording to Adept and Master, and add an explicit 'Novice uses the Basic-card floor 1/2/3' clause. Needs Bruce because it is a formula-versus-floor rules call, and the identical parenthetical in 21-glossary.qmd:47 must carry the same wording book-wide (see R1).
