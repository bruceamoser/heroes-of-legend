# Heroes of Legend working playtest

Working rules and test catalog version 0.2 — October 12, 2026.
Plain rules and test material, not book prose.

**Read [revision status](revision-status.md) before using catalog prototypes or
simulation findings.** Current results use version 0.2; version 0.1 is archived under history/.

**Authority:** Bruce's agreed decisions are marked **Agreed**. New catalog entries,
numbers, timings, and implementation choices are **Provisional**, including every
named card unless explicitly identified as universal. Approval of testing is not
approval of every proposed rule. Quarto chapters remain the published-source tree;
this directory is the independent working reference for the redesign.

The JSON catalog is the structured companion to the Markdown tables. The generator
renders those tables from one source so costs and prerequisites cannot drift between
human-readable and machine-readable copies. It is test tooling, not a VTT design.

## Scope

Four ancestry options; selectable origin pairs; all nine class requirements,
discipline prices, and signature choices; level 1/3/7 builds; a deliberately small
shared-card catalog. Each ancestry has five traits and each signature milestone has
three options. This is a starting kit, not a complete commercial catalog.

Layout, publication tooling, illustration, and polished narrative are deferred.
Legacy catalogs are archived by immutable reference and manifest in [legacy](legacy/README.md).
Do not consult them to supply missing mechanics. Record a gap instead.
