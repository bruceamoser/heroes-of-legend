# Abilities

All named purchased/signature cards below are provisional test designs. Tier level
1/3/7, price 2/4/8; all listed discipline ranks required before purchase. Signature
requirements are class + level only. Card types are provisional categories.

## Universal reference — Agreed permission, provisional numeric profiles

Everyone receives these references, not DP purchases. No equipment is automatically
granted by a universal card. Costs/ranges below marked provisional where not settled.
All actions repeatable unless constrained by their normal action allowance.

| Card | Cost | Roll / effect |
|---|---|---|
| Basic Melee | Main | Brawn, adjacent, melee weapon, physical 2/3/5 (provisional) |
| Basic Ranged | Main | Agility, range 8, ranged weapon/ammunition, physical 2/3/5 (provisional) |
| Basic Throw | Main | Brawn, range 3, suitable carried item, physical 2/3/5 (provisional); item ends at target square |
| Basic Unarmed | Main | Brawn, adjacent, physical 1/2/4 (provisional) |
| Defend | Maneuver | One Boon to defense rolls until start of your next turn |
| Aid | Maneuver | Adjacent ally, plausible assistance: Boon to next declared action roll before your next turn (provisional timing) |
| Disengage | Maneuver | No movement opportunity attacks this turn |
| Movement | Movement | Move up to Speed; converted Maneuver grants another allowance |
| Shield Block | Reaction | Before eligible defense, shield gives Boon until start of your next turn; DA judges blockability |
| Stabilize | Maneuver | Adjacent Dying PC, no roll, stable at 0, clear death marks |
| Force | Main | Brawn, adjacent physical obstacle/creature: 1/2/3 progress, grapple reduction, or squares of push |

A basic Strong 5 deals 2 against resistance 3, but only 1 against resistance 4+.
This addresses the low-tier armor test, not a universal post-resistance floor of 2.
