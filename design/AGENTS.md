# Fresh design workspace

Bruce explicitly directed a fresh start on October 12, 2026. Do not use legacy
book cards, playtest cards, their JSON, or their Python definitions as design
references. Derive new cards from the agreed conversation decisions and the rules
recorded here. Old experiments are historical evidence only.

Markdown is the editable source in this directory. Edit it directly. Do not
regenerate it from playtest/tests/catalog.py. Index tooling may read Markdown;
it must never overwrite authored card text.

Agreed foundations, approved starting numbers, and new proposals must remain
visibly distinct. All new named options and per-card numbers are proposals until
Bruce approves them. No new proposal silently changes the foundation. Use stable
IDs and links. No book layout work or new balance simulation until catalog review.

Start from the player experience: flavor, clear fictional action, teamwork and
memorable choices. Numerical consistency supports play; it is not the sole
acceptance criterion. Reference other RPGs through the local library, cite the
actual passage consulted, and write original HOL expressions of useful ideas.
