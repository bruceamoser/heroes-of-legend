# Current authoring workspace

The Markdown in this directory is the approved rules and catalog source. The two
Typst books consume it. Bruce confirmed this baseline on October 17, 2026; Git
history is the archive. Do not reintroduce earlier rules, catalogs or simulations.

Read the relevant current rule before editing a card. Preserve stable IDs and
links. Keep player abilities separate from monster abilities and summon profiles.
Narrative describes the imagined action; Rules states the precise result.

Approved catalog entries are not pending proposals. Mark genuinely new rules for
Bruce’s review. CV estimates and balance questions remain explicitly provisional;
approval of content is not proof of balance. Do not silently change mechanics as
part of formatting or cleanup.

See the root AGENTS.md and .github/copilot-instructions.md for workflow, build and
review requirements. Generated outputs must never become an editable rules source.
