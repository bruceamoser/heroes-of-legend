# Discipline coverage

The active catalog contains eleven nonmagical disciplines, seven magical disciplines and Spellcraft. Each has four paths. The source validator checks sequential costs and level gates, first-entry origin grants, and exact prerequisites for two-, three- and four-discipline combinations.

The older flat-card rank coverage model is retired. Learning graph validation is in player-book/nonmagical/build.py; PDF coverage is in player-book/audit.py.
