# Bestiary

The current catalog contains **192 creatures**, **126 monster abilities** and
**73 summoned forms**. The [action expansion](action-coverage.md) is a working review draft beyond
starter kit v16.3.0. CV and encounter budgets remain estimates to test in play.

Edit authored Markdown directly. A creature has only the abilities printed on its
card; category and narrative grant no additional mechanics. Ordinary creatures and
summoned energy forms use their respective profiles.

Run `python3 design/bestiary/audit.py` and `python3 design/bestiary/art/audit.py`.
These validate structure, outcome perspectives, CV arithmetic and illustration
coverage. They do not simulate combat or certify encounter balance.
