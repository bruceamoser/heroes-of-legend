# Bestiary — first complete core roster

**Status: proposal for Bruce’s review.** These are fresh HOL creatures, not
conversions of the old book. All creature statistics, summon permissions and CVs
are provisional. The established player-roll and action rules remain intact.

Read the [approved compact-layout migration](compact-layout-review.md),
the [full revision review](review.md) and [per-creature ledger](creature-review.md).
The roster now has 192 creatures, 93 monster abilities and 73 explicit summon
choices. Read the [Bestiary 1 coverage survey](family-survey.md), use the
[classic family finder](families.md), and review the [108 additions](expansion-review.md).
This remains an authoring catalog, not a balance certification.

Start with [using creature cards](procedure.md), then the [roster](roster.md).
[Monster abilities](../monster-abilities/README.md) are a separate catalog: they
have no DP price and cannot be purchased as character abilities. A creature only
has abilities printed on its card. Category names grant nothing by themselves.

Each creature has a reason to be in the adventure, signs the heroes can recognize,
a fighting pattern and an alternative to simply trading attacks. Mortal adversary
entries describe a job or allegiance, not an ancestry’s moral nature. Use ordinary
names and local relationships to make any of them a person.

Edit the Markdown cards directly. `python3 design/bestiary/audit.py` checks the
catalog and recalculates CV estimates without rewriting prose. It is not a combat
simulation and does not establish encounter balance. No final book layout is
attempted here.
