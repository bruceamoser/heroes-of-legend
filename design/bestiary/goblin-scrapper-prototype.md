# Goblin Scrapper layout reference

Use the maintained [Goblin Scrapper](creatures/goblin-scrapper.md) for all current
statistics, actions, CV and play text. This reference no longer duplicates its
stat block. Git history retains the original approved layout sample.

The current [compact card layout](card-layout.md) incorporates Bruce’s Goblin and
Adder reviews: two stat columns, unique action tables with defense and damage
type, complete outcomes, concise details, world information and a summon marker
when applicable. Universal options are taught once in the book introduction;
internal design notes stay outside the printed card.
