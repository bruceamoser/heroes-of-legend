# Six level-1 characters — complete creation walkthroughs

Each example follows its level-0 origins and learning, then a separate level-1 class and learning stage. Access costs 1 DP; the first three sequential steps cost 1/2/2 DP. No level-3 endpoint is learned early. The ledgers include duplicate compensation, ancestry DP and expiration of each creation pool. Equipment is purchased separately.
