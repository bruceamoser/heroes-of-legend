# Web Cast

*White strands snap between the pillars and tighten around boots and wrists.*

## Rules

**ID:** monster-web-cast

**Status:** Proposed monster-only ability; not purchasable with DP.

**Action:** Main Action

A printed web attack applies Slowed 1/2/3 on Weak/Standard/Strong, without damage. The strands decay normally. The target or an adjacent helper can spend Main to remove 1 Slowed from this source; fire damage to the target removes all of it after resolving that damage. Webbing is not a free, one-sided grapple.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
