# Rally

*A barked order cuts through the noise, and a wavering fighter finds their footing.*

## Rules

**ID:** monster-rally

**Status:** Proposed monster-only ability; not purchasable with DP.

**Action:** Maneuver

Choose one ally within 3 squares that can hear this creature. Remove 1 Frightened from that ally. Alternatively, grant 1 Boon to the ally’s next attack before the start of this creature’s next turn (1 Threat Bane if an NPC attacks a player). Multiple copies of this named bonus do not stack. No free attack is granted.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
