# Stalking Step

*It folds into the broken light, leaving only a leaf moving where it stood.*

## Rules

**ID:** monster-stalking-step

**Status:** Proposed monster-only ability; not purchasable with DP.

**Action:** Maneuver

Move up to 2 squares, paying terrain costs from this allowance. This is voluntary movement and can provoke. It does not grant Hidden. A separate Hide action still needs concealment and a roll when uncertain.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
