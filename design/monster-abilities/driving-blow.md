# Driving Blow

*The blow lands with enough force to send its victim stumbling backward.*

## Rules

**ID:** monster-driving-blow


**Action:** Main Action

Use the printed attack. Standard pushes the target 1 square; Strong pushes it 2. Apply Stability before moving. This is a rider, not a separate attack or Force action.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
