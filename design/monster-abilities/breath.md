# Gathered Breath

*Its chest swells and light leaks between its teeth; there is one terrible instant to scatter.*

## Rules

**ID:** monster-breath


**Action:** Main Action

Use the printed area attack. It is not a spell. After using it, this creature cannot use this named attack on its next turn. Each affected player defends separately; a player-controlled creature rolls once at the worst target modifiers. Allies in the area are affected. The first use is available; describe the visible preparation before resolving it, not as an extra interrupt window.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
