# Mimic Shell

*The hinges are teeth; the leather grain shivers like skin.*

## Rules

**ID:** monster-mimic-shell

**Status:** Proposed monster-only ability; not purchasable with DP.

**Action:** Passive

While still, this creature may resemble the ordinary object named in its entry. Reason search can expose the disguise using normal perception outcomes; touching or opening it reveals it before its next action, not a free attack. Once exposed, it needs concealment and a Hide action to become Hidden again.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
