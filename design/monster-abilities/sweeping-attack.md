# Sweeping Attack

*A great limb scythes across the ground, forcing everyone nearby to move.*

## Rules

**ID:** monster-sweeping-attack


**Action:** Main Action

Use the printed attack against up to two different creatures within its printed reach, including allies if deliberately selected. Each player target defends separately. A player-controlled sweep rolls once at the worst target modifiers. This replaces, rather than accompanies, a single-target attack.

**Limits:** Only creatures whose entries list this ability possess it. Printed
entry values and restrictions apply; no ability grants unlisted actions.
