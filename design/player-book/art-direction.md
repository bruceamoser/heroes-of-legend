# Illustration and card revision — October 16, 2026

Bruce's review in issues #1218–#1220 replaces the earlier empty-space filler approach.
An illustration has one placement in the book. Repeating functional discipline
symbols, tier marks and the book logo is intentional; repeating scene art is not.
Class portraits belong on their class introductions. Signature pages use relevant
objects; shared ability pages may use gear, magical objects or landscapes. The
finite art selection is never cycled to occupy every available gap.

Reference inspected: Pathfinder Second Edition Core Rulebook, local PZO2101E.pdf,
PDF pages 288–291 (printed pages 287–290). The gear introduction uses isolated
caltrops beside relevant explanation; the table spread needs no character filler;
class kits use small identifying symbols; ordinary equipment objects carry visual
interest without occupying an entire character portrait panel. These are layout
principles, not copied illustrations or text. HOL retains its own forest, gold
and ivory palette and inked illustration style.

Ancestry traits, cultures, backgrounds and disciplines use the same bordered card
language as abilities, with solid headers and narrative/rules separation. Rank
purchase rules and the class cost matrix appear in the discipline chapter.
Discipline symbols use distinct gold silhouettes, with a high-contrast numeral
over the lower edge so their identifying contours remain visible.

New images are generated with the built-in image generator. The exact prompts,
transparent-background requests and intended roles are saved in
`art/revision-prompts.json`; originals remain in `art/interior/`. Replaced ornate badges and scenic class portraits are available in Git history;
the current source keeps the readable symbols and transparent cutouts. Generated placement data
and the PDF audit check illustration uniqueness across the whole book.


## Transparent class portraits and reference art

Each class introduction now uses a transparent cutout, preserving its established
character, equipment and animal companion. The ten edits have real alpha channels;
no painted rectangular landscape remains. Original scenic inputs are available in Git history before the current-system cleanup.
Exact edit prompts and source/output paths are in art/class-cutout-prompts.json.

The starting-HP reference uses a resilient oak rooted through broken stone; the
class-discipline matrix uses a quiet courtyard of study and training. Their prompts
are in art/reference-prompts.json. These additions follow the single-use policy.
