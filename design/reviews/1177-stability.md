# Character Stability review

Approved Stability: default 0, explicit grants only, highest source, maximum 3;
each newly struck creature consumes movement once in a collision chain.

Six protective cards now grant Stability rather than duplicate distance reduction.
The dwarf ancestry roll benefit stays a Boon. No ancestry, attribute, armor weight
or class automatically grants Stability. Existing character sheets now record it.

All displacement remains useful against unbraced targets. Short push riders can
be fully resisted; damage, Prone, Slowed and other independent effects still apply.
We did not inflate every distance to defeat the new defense. Hurl Aside, Storm on
a String (object only), and larger Force results already have their own niches.
Master cards with small incidental pushes retain their primary spells/other effects.

Two rescue cards explicitly propose ignoring Stability for willing rescue movement;
this is a card-specific exception for review, not a universal voluntary opt-out.
