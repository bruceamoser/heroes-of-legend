# Reconstruct the Event

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** An accessible evidence set; one hour

DA declares the objective, stakes and any cumulative target before the roll. Progress is not automatic completion. No routine roll when there is no consequence.

- **Weak:** 1 progress toward an evidence-supported account.
- **Standard:** 2 progress; identify one gap in the account.
- **Strong:** 3 progress; identify the next kind of evidence that could resolve a gap.

**Duration:** Instant

**Equipment / acquisition:** None.

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Scholarship 3

**Type:** Skill

**Limits:** Repeatable within the normal action economy.
