# Coordinated Rush

**Action:** Main Action · **Attribute:** None — no roll

**Target / range / shape:** As specified in the effect

Two willing allies within 4 squares each move 2 squares without provoking, then each makes a free Basic Melee attack if a target is adjacent. No chains; no specialty attacks.

**Duration:** As specified; otherwise immediate

**Equipment / acquisition:** None.
