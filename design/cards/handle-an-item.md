# Handle an Item

- **ID:** handle-an-item
- **Status:** Agreed foundation; any proposal is identified in the effect.
- **Type:** Universal
- **Tier / minimum level:** Universal
- **DP:** Not purchased
- **Requirements to learn:** None
- **Action:** Varies
- **Attribute:** None — no roll
- **Target / range / shape:** An accessible item
- **Duration:** Instant
- **Limits:** Repeatable within the normal action economy.
- **Equipment / acquisition:** None.

## Resolution

| Weak | Standard | Strong |
|---|---|---|
| No roll; apply the effect. | No roll; apply the effect. | No roll; apply the effect. |

Drawing a weapon is included in its attack action. Dropping is free. Proper stowing or picking up costs a Maneuver. Ordinary item use follows its own card. No free two-handed grip exception is assumed.
