# Handle an Item

**Action:** Varies · **Attribute:** None — no roll

**Target / range / shape:** An accessible item

Drawing a weapon is included in its attack action. Dropping is free. Proper stowing or picking up costs a Maneuver. Ordinary item use follows its own card. No free two-handed grip exception is assumed.

**Duration:** Instant

**Equipment / acquisition:** None.

---

**Tier / minimum level:** Universal · **DP:** Not purchased · **Requirements to learn:** None

**Type:** Universal

**Limits:** Repeatable within the normal action economy.

**ID:** handle-an-item · **Status:** Agreed foundation; any proposal is identified in the effect.
