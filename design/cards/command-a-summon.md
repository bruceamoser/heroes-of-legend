# Command a Summon

- **ID:** command-a-summon
- **Status:** Agreed foundation; any proposal is identified in the effect.
- **Type:** Universal
- **Tier / minimum level:** Universal
- **DP:** Not purchased
- **Requirements to learn:** None
- **Action:** Main Action or Maneuver
- **Attribute:** None — no roll
- **Target / range / shape:** One of your summons within its tether
- **Duration:** Instant
- **Limits:** Repeatable within the normal action economy.
- **Equipment / acquisition:** None.

## Resolution

| Weak | Standard | Strong |
|---|---|---|
| No roll; apply the effect. | No roll; apply the effect. | No roll; apply the effect. |

Main grants the summon Main plus Maneuver; Maneuver grants it Maneuver plus movement. One command per summon per turn. Same conversions apply. Two different summons can receive your two commands. A new summon receives an immediate free Main command, counted as its command.
