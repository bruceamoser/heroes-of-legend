# The Walking Toolbox

**Action:** Main Action · **Attribute:** None — no roll

**Target / range / shape:** One visible free square within 2 squares.

Unfold a tool-carrying construct: HP 4, Speed 4, no resistance or attack; carries 2 Bulk. Counts as a summon with normal commands, immediate command, tether and one-scene duration. With a commanded Maneuver it may bring an adjacent held tool to a willing adjacent ally, but never craft or grant extra crafting attempts.

**Duration:** Immediate unless a duration is given above; conditions use normal decay.

**Equipment / acquisition:** No item needed unless named above.

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Craft 2

**Type:** Skill / Crafting

**Limits:** Repeatable; pay the action each time and follow any stated limit. No earlier path card is required.
