# Return Stroke

*You turn a successful guard into the beginning of your own blow.*

## Rules

**Action:** Reaction · **Attribute:** None — no separate roll; resolve Basic Melee using Brawn

**Target / range / shape:** An adjacent melee attacker, after you resolve a Strong defense against it.

After a Strong defense against an adjacent melee attacker, make a free Basic Melee attack against it. Free attacks trigger no further free attacks.

Each granted Basic Melee attack uses its attacker’s Brawn and Basic Melee outcomes; this card adds no separate roll beyond any roll it explicitly requires.

**Duration:** Resolve once at the stated trigger; applied conditions follow normal decay.

**Equipment / acquisition:** None.

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Blade; minimum level 3

**Type:** Signature

**Limits:** Normal action economy; any additional limit is printed above.
