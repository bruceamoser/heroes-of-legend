# Shielding Step

*You are already moving before your friend sees the blow.*

## Rules

**Action:** Reaction · **Attribute:** None — no roll

**Target / range / shape:** An adjacent willing ally, before an attack resolves

Become the target if legal.

**Duration:** Instant

**Equipment / acquisition:** Requires a shield. Grants one ordinary shield, Bulk 1, if absent.

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Guard 1

**Type:** Skill

**Limits:** Pay the printed action and costs each use; any stated daily or scene limit also applies.
