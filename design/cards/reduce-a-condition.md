# Reduce a Condition

- **ID:** reduce-a-condition
- **Status:** Agreed foundation; any proposal is identified in the effect.
- **Type:** Universal
- **Tier / minimum level:** Universal
- **DP:** Not purchased
- **Requirements to learn:** None
- **Action:** Main Action
- **Attribute:** None — no roll
- **Target / range / shape:** Self or one adjacent creature
- **Duration:** Instant
- **Limits:** Repeatable within the normal action economy.
- **Equipment / acquisition:** None.

## Resolution

| Weak | Standard | Strong |
|---|---|---|
| No roll; apply the effect. | No roll; apply the effect. | No roll; apply the effect. |

With a plausible method, reduce Bleeding, Burning, or Freezing by 1. This is not a general cure for all conditions. A persistent source can require a specific remedy.
