# Call the Hunting Cat

*You beckon, and a sleek hunter pads into place with its gaze already fixed on the struggle.*

## Rules

**Action:** Main Action · **Attribute:** None — no roll

**Target / range / shape:** One visible free square within 3 squares.

Call a hunting cat: HP 8, Speed 6, resistance 0. Main attack uses controller Guile, adjacent, physical 3/4/6; Strong knocks prone. It may Move or Defend when commanded. Normal summon rules, immediate Main command and 6-square tether apply. Lasts one scene; no prerequisite hound card.

**Duration:** Until the scene ends, unless ended earlier as stated above.

**Equipment / acquisition:** No item needed unless named above.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Calling 2

**Type:** Magic

**Limits:** Pay the printed action and costs each use. No earlier path card is required; any stated daily or scene limit also applies.
