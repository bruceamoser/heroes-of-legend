# Disengage

- **ID:** disengage
- **Status:** Agreed foundation; any proposal is identified in the effect.
- **Type:** Universal
- **Tier / minimum level:** Universal
- **DP:** Not purchased
- **Requirements to learn:** None
- **Action:** Maneuver
- **Attribute:** None — no roll
- **Target / range / shape:** Self
- **Duration:** Remainder of this turn
- **Limits:** Repeatable within the normal action economy.
- **Equipment / acquisition:** None.

## Resolution

| Weak | Standard | Strong |
|---|---|---|
| No roll; apply the effect. | No roll; apply the effect. | No roll; apply the effect. |

Your voluntary movement does not provoke opportunity attacks for the rest of this turn.
