# Call Spirit: Adept

*You call a name into the empty place beside you. An answering presence straightens as if taking up an old duty.*

## Rules

**Action:** Main Action · **Attribute:** None (no roll)

**Target / range / shape:** One visible unoccupied placement within 3 squares that fits the chosen form's entire footprint.

Choose one Spirit entry from the summon selection with a minimum tier of 3 or lower. Call one instance using its summon profile. Choose the form anew each casting. It remains for one scene.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Calling 2

**Type:** Magic / Summoning

**ID:** call-a-sentinel
