# Storm on a String

*Choose one visible unattended object of Bulk 1 orless within 5 squares. Move the object up to 5 squares toward you along an open path. Catch it if it reaches your free hand, or leave it in the last square reached.*

## Rules

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** One visible unattended object of Bulk 1 orless within 5 squares.

Move the object up to 5 squares toward you along an open path. Catch it if it reaches your free hand, or leave it in the last square reached.
