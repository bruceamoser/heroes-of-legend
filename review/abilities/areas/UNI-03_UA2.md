# UA2: The Last Word

**Status:** Approved 2026-10-29.

## Current concept

When you enter Dying, make one final attack before the Dying procedure resolves.

## Proposed final text

# The Last Word

*The blow lands, the world goes white, and you spend your last breath on one final strike.*

## Rules

**Action:** Reaction · **Attribute:** None (no roll)

**Target / range / shape:** Self, when you enter Dying.

Take one Main Action before the Dying procedure. Then mark the wound and resolve Dying normally. Once per scene.

**Duration:** Instant.

**Equipment / acquisition:** None.

---

**Tier:** Adept · **Minimum level:** 3 · **DP:** 3 · **Requirements to learn:** None

**Type:** Utility

**Tags:** Universal / Reaction / Recovery

**Limits:** Once per scene; one Main Action.

**ID:** the-last-word

## Why this is not the baseline

The Dying procedure offers Grit or a death roll at the start of your turn. A Dying character does not normally act. This is a new permission: one Main Action before Dying takes hold.

## Power note

At 3 DP it is a strong last-stand effect. It is self-only, once per scene, and you still enter Dying. The Main Action uses its normal rules.
