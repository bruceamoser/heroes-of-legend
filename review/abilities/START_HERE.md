# Abilities review — published control set

This directory is the published record of the Heroes of Legend abilities review.
The live working copies live in the review workspace; `work/publish_control_set.py`
publishes them here.

- `README.md` — control-set index and workspace rules.
- `AREAS.csv` / `AREA_TRACKER.md` — 18-area status.
- `CHANGE_LEDGER.csv` — approved and proposed changes.
- `workbooks/` — the 19 review workbooks.

See `AREA_TRACKER.md` for the authoritative current area and status.
